"Aux Cable" is a self-hosted Discord "bot" that allows you to stream any input from your computer to a voice channel on Discord.

Practical uses include:

- Listening to music together
- Live music (e.g. guitar, bass, keyboard, DJ mixer, etc.)
- Extra microphone input (e.g. for a second person in the same room, or your cat)
- TTRPG sound effects
- Streaming audio from another device (eg. a phone, tablet, or iPod) through a Line-In port.
- Streaming audio from your computer without needing to share your screen
- Streaming audio from another computer (e.g. a second computer in the same room, or a Raspberry Pi)
  - The app can be run headless, so audio can be streamed to Discord without a GUI.

## Getting Started

[Download the latest release of Aux Cable here!](https://github.com/NotJustAnna/aux-cable/releases/latest)

You'll need to create a Discord bot to use Aux Cable. Instructions can be found on the app, if needed.
